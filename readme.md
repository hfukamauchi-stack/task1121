# ①課題名
Singapore Infantry（シンガポール食巡りガイド）

## ②課題内容（どんな作品か）
- シンガポールのおすすめ飲食店26店舗を掲載した、食をテーマにした旅行ガイドアプリ。
- お店をカテゴリー別に検索したり、マップ上から位置関係を確認したりすることができる。
- 気になったお店をお気に入り登録し、訪問済みのお店や食事の感想を記録することで、自分だけのシンガポール食べ歩きガイドを作成できる。

## ⑤工夫した点・こだわった点
- 観光ガイドに載っている定番情報だけでなく、現地での食べ歩きを楽しむことをコンセプトに、雑誌のようなデザインを意識した。
- カテゴリーごとにお店を絞り込める機能や、マップ上からお店を探せる機能を実装し、直感的に操作できるよう工夫した。
- LocalStorageを活用し、お気に入り・訪問済み状況・メモをブラウザに保存できるようにした。ページを再読み込みしても記録が残る仕様にした。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- JavaScriptを用いて、店舗情報の表示やカテゴリーによる絞り込み、訪問状況に応じた画面更新など、複数の機能を連動させることに苦労した。
- LocalStorageを活用したデータの保存・読み込みを理解し、ユーザーの操作内容を保持する仕組みを実装することが難しかった。
- 今後は実際の地図APIを導入し、店舗の正確な位置情報や経路検索を表示できるようにしたい。また、店舗の写真や営業時間、実際に訪問した際の記録などを充実させ、より実用的な旅行ガイドアプリに発展させたい。
